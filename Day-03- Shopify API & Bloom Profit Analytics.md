# Day 3 — Shopify API & Bloom Profit Analytics

## 📊 Shopify API Access

* Learned how to provide the required permissions in a Shopify app.
* Understood how app permissions are used to access Shopify data through APIs.
* Learned how to obtain an **API access token**.
* Understood that the access token can be used to retrieve Shopify data such as:

  * Products
  * Orders
  * Other permitted store data

## 🔎 Shopify Reports & Queries

* Learned a basic introduction to how Shopify reports and data queries work.
* Understood that querying Shopify data has some similarities to SQL concepts such as selecting and filtering data.
* Learned that Shopify's querying/reporting approach has its own syntax and structure.

## 🌸 Bloom Profit Analytics

Learned about additional sections/features in Bloom with **Sandana**:

* **Order Profits**
* **Product Profits**
* **Dashboard**
* **Targets**
* **My Metrics**

Explored how these sections are used to understand sales, product profitability, performance, targets, and business metrics.
